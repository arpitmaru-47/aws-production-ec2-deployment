

# EC2 Monitoring

## CloudWatch
Amazon CloudWatch was used to monitor EC2 instance metrics.

## Metrics
- CPU Utilization
- Network In
- Network Out
- Status Check Failed

## CPU Alarm
Alarm Name: production-ec2-high-cpu

Purpose:
Monitor high CPU utilization and identify possible performance issues.

Note:
Review the actual alarm threshold and evaluation settings in AWS Console before documenting exact values.
